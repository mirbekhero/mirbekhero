Бот-переводчик в Telegram

Высокоскоростной асинхронный Telegram-бот, предназначенный для мгновенного перевода сообщений между **русским** и **английским** языками. Создан с использованием `aiogram 3.x` и `deep-translator`.
 Основные характеристики
* **Автоматическое определение языка**: автоматически определяет исходный язык и переключается между RU ➔ EN или EN ➔ RU.
* **Высокая производительность**: Использует `ThreadPoolExecutor` для обработки переводов без блокировки работы бота.
* **Фильтр безопасности**: Включает настраиваемый фильтр «BAD_WORDS», предотвращающий перевод нецензурных выражений.
* **Интеллектуальное развертывание**: автоматически определяет, запущено ли приложение на локальном ПК или в среде **PythonAnywhere**, и настраивает необходимые параметры прокси-сервера.
